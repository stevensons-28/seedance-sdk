# Seedance SDKs for Python and Node.js

Unofficial client libraries for ByteDance's Seedance video models (Seedance 2.5, 2.0, 2.0 Fast and 2.0 Mini) through the [KreatorFlow Seedance API](https://kreatorflow.ai/seedance-api). Seedance is a ByteDance model; KreatorFlow is an official partner of BytePlus, a ByteDance company.

| Language | Package | Folder |
| --- | --- | --- |
| Python 3.9+ | [`pip install seedance`](https://pypi.org/project/seedance/) | [`python/`](python/) |
| Node.js 18+ / TypeScript | [`npm install seedance-sdk`](https://www.npmjs.com/package/seedance-sdk) | [`node/`](node/) |

Get a key at [developers.kreatorflow.ai](https://developers.kreatorflow.ai/?section=keys). Docs: [Seedance API reference](https://kreatorflow.ai/seedance-api/reference) and the [Python and Node.js tutorial](https://kreatorflow.ai/guides/seedance-api-python-node). Prices: [Seedance pricing](https://kreatorflow.ai/seedance-pricing).
